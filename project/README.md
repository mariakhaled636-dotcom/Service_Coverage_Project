# اختيار مواقع الخدمات

مشروع مقارنة GA وPSO وACO مكتوبة داخل المشروع، مع حل جشع ومرجع دقيق للحالات الصغيرة وحد للمقارنة للأحجام الأخرى. البيانات مولدة وليست بيانات جهة حقيقية.

## التشغيل

استخدم Python 3.12 أو أحدث. من مجلد project:

```text
python -m pip install -r requirements.txt
python main.py
python verify.py
```

يعيد الأمر الثاني إنشاء results. تجربة سريعة تحفظ النتائج في مجلد مستقل:

```text
python main.py --runs 2 --output ../trial_results
python verify.py --results ../trial_results
```

لإعادة أول تشغيل لكل خوارزمية وحالة ومقارنة الحل وسجل التقارب:

```text
python verify.py --rerun
```

## التجربة والملفات

توجد ثلاثة أحجام ومسألتان لكل حجم وعشر تشغيلات لكل خوارزمية ومسألة، أي 180 تشغيلة. بذور البيانات والبحث والإعدادات ثابتة ومحفوظة في experiment.json. تتضمن التهيئة الحل الجشع نفسه للطرق الثلاث. عدد تقييمات الهدف متساو داخل المشروع، لكنه لا يعني تساوي الكلفة الحسابية لبناء الحل. تقاس الأزمنة خارج حساب المرجع والرسم وتتغير بحسب الجهاز.

- results/experiment.json: كل بيانات المسائل والحلول والمنحنيات والإعدادات والبذور.
- results/trials.csv: نتيجة كل تشغيل وزمنه وفجوته عن المرجع.
- results/summary.csv: ملخص الجودة والزمن والثبات حسب الحجم والخوارزمية.
- results/convergence.png: متوسط أفضل هدف للمسألة الأولى من كل حجم عبر التشغيلات العشر.
- results/comparison.png: فجوة المرجع والزمن حسب الحجم.
- verify.py: فحص القيود والهدف والمراجع والحلول والمنحنيات وإعادة حساب الملخصات.

الانحراف المعروض في الملخص هو متوسط الانحرافات المعيارية العينية داخل مسألتي الحجم. لا يخلط تغير البيانات بتغير بذرة البحث. المرجع في الصغير دقيق؛ وفي المتوسط والكبير حد لا يدعى أنه أمثل.

## عرض الموقع

افتح index.html في المجلد الأب بالنقر المزدوج. اختر الحالة والخوارزمية والتشغيل لعرض النتيجة المحفوظة. الصفحة لا تنفذ خوارزميات Python. عند إعادة التجارب يعاد توليد العرض بواسطة أمر التصدير التالي:

```text
python export_web_data.py
```

يمكن عرض الموقع دون إنترنت أو تثبيت مكتبات؛ تثبيت المكتبات مطلوب فقط لتشغيل التجارب والتحقق. التقرير وأسماء الفريق في Report.docx. توزيع مهام المراجعة والعرض مقترح ويجب مراجعته وفق العمل الفعلي لكل عضو.

الفهارس تبدأ من الصفر. الهدف تعظيم وزن الطلب المغطى مع اختيار k مواقع دون تكرار. الفجوة هي مئة مضروبة في الفرق بين المرجع والهدف، مقسوما على المرجع. الأحجام هي 12 و24 و36 موقعا؛ عدد تقييمات الهدف 1220. الخوارزميات في search.py والمسألة والمراجع في coverage.py.
